# How to Contribute to the Project

Thanks for interest in the project! 🙌

## How to Suggest Improvement

1. Create an Issue describing the problem or idea
2. Fork the repository
3. Make changes
4. Send a Pull Request

## Pull Request Rules

- One PR = one fix/improvement
- Describe in PR what and why you changed
- New llms.txt examples add to `examples/` folder
